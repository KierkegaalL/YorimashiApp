直前の実装に対して、**実装後チェックループ**（.claude/rules/build-commands.md）を実行してください。

手順:

1. チェック専用のサブエージェント **`reviewer`（Sonnet 5 固定）** を `Agent` で起動する（既存/作成済みファイルへの実行のため：CLAUDE.md 原則8）。以下の観点で直近の変更を確認させる:
   - **対称性チェック**（Live2D/スプライトセットの片方だけ直していないか。非対称なら理由が明記されているか）— constraints.md 最重要ルール
   - `docs/detailed-design/` の決定事項との整合（実測に基づく決定に反していないか）
   - 正本との齟齬（要件・基本設計=Notion / UI=`docs/mockups/control-panel.jsx` / clips=`manifest.json`）
   - 破ってはいけない制約（127.0.0.1限定、トークン認証、`chatAdapter`既定`mock`、dev-assets隔離）
   - 不具合（バグ、例外処理漏れ、型不整合）・冗長なコード
2. 指摘リスト（該当ファイル:行・種別・修正案）を受け取る
3. 指摘が **1件以上** → 修正し、手順1へ戻って再チェック
4. 指摘が **0件** → ループ終了として日本語で完了報告

大きな変更は、ファイル単位・機能単位に分割して `reviewer` を起動する（1回の巨大な呼び出し中にセッション制限へ達すると検証結果を取りこぼすため）。
