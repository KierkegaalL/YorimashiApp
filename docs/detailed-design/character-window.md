# character-window.md — キャラクター表示ウィンドウ詳細設計

**ステータス**: 未着手
**対応FR**: FR-6
**関連**: basic-design.md 5.1(CharacterRenderer)、security.md 7章(モデルアセット配信)

## 背景

FR-6は「透過・枠なし・常に最前面・クリックスルー」という要件までは確定しているが、以下の挙動の詳細は未確定。

## 検討すべき論点

1. **マルチモニタ挙動**
   - 複数モニタ環境で、キャラクターウィンドウはどのモニタに表示するか(初回はプライマリモニタ固定か、最後に表示した位置を記憶するか)
   - モニタ構成が変わった場合(モニタを外した等)、ウィンドウ位置をどう補正するか

2. **初期配置ロジック**
   - 初回起動時、キャラクターをどの座標に配置するか(画面の右下等、決め打ちにするか)
   - `config.general.windowPosition`(nullable)がnullの場合のデフォルト計算方法

3. **右クリックメニューの項目一覧**
   - 想定される項目: 「Control Panelを開く」「モード切替(Code/Chat)」「クリックスルーの一時解除」「終了」等
   - 項目の並び順・アイコンの有無

## 未確定のまま残すリスク

初期配置ロジックが未確定なまま実装すると、複数モニタ環境で「見えない場所にウィンドウが出る」障害が起きやすい。実装着手前に最低限「初期配置」だけは決めておくことを推奨。
