# lipsync.md — リップシンクとstreaming表示の同期方式

**ステータス**: 未着手
**対応FR**: FR-3(Chat Adapter)、FR-4(EmotionEngine)

## 背景

Chat Adapterのstreaming応答表示と、キャラクターの口パクアニメーションをどう同期させるかが未確定。v1のスコープはテキスト+アニメーションのみで、音声(TTS)は将来検討のため、**音声波形に基づくリップシンクではなく、テキスト表示速度に基づく口パク**になる想定。

## 検討すべき論点

1. **同期の粒度**
   - 1文字表示ごとに口を開閉させるか、単語単位か、一定間隔のランダム開閉にするか

2. **Live2D側の実装**
   - 口パク用のパラメータ(`ParamMouthOpenY`等)をどの頻度で更新するか

3. **スプライトセット側の実装**
   - 静止画1枚からAI生成した動画クリップには「口パクだけ」の専用クリップは無い想定。streaming中は`thinking`または専用の`talking`状態を新設するか、既存の10状態に含めるか(EmotionEngineの状態セットに影響するため、FR-4の変更を伴う可能性がある)

4. **mock/real両方での動作**
   - mockモードでも同様の口パク表現を行うか(答えは恐らくYES、モック段階でも動作確認したいため)
