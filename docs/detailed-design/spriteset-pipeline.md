## 背景

スプライトセットの取り込みパイプライン(クロマグリーン合成・色キー抜き・アニメーションWebPエンコード)の処理内容は基本設計で確定済みだが、実装に使う具体的な画像処理ライブラリは未選定。

## 検討すべき論点

1. **クロマグリーン合成**
   - Node.js側の画像処理ライブラリ候補: `sharp`(ネイティブ依存あり、高速)、`jimp`(Pure JS、依存が軽い)
   - macOS + Electronという実行環境で、ネイティブ依存(sharp)のビルド・配布上の懸念があるか要検証

2. **色キー抜き(境界連結判定)**
   - 「背景色に近い画素のうち、画像の縁に連結した領域のみを背景と判定する」というアルゴリズムを、上記ライブラリのどちらでどう実装するか(픽셀単位のフラッドフィル処理が必要になる可能性が高く、sharpの標準APIだけでは完結しない可能性がある)

3. **アニメーションWebPエンコード**
   - Node.jsから利用できるWebPエンコーダの選定(`sharp`はWebP出力に対応、アニメーションWebPの複数フレーム合成が可能か要確認)
   - もしくは`ffmpeg`(バイナリ同梱)を使い、mp4/webmからアニメーションWebPへ直接変換する経路も候補

4. **配布時のバイナリサイズ・ライセンス**
   - `sharp`はネイティブバイナリを含むため配布サイズが増える。`ffmpeg`も同様。権利情報タブのOSSライセンス一覧(FR-12)に追加が必要になる
